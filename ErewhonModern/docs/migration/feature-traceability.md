# Feature traceability

This record maps each legacy Erewhon feature, F-001 to F-022, to its modern implementation under `ErewhonModern/` and the tests that prove it, or to the recorded reason it has no implementation. Reasons are cited by D-ID from `docs/migration/decision-log.md`; `B-`, `C-`, `Q-` and `EE-` IDs refer to `docs/migration/behaviour-catalogue.md`.

## Machine-read format

`TraceabilityCoverageTests` reads this file. The format is fixed by D-48:

- The features are one table under `## Features` with the header `| ID | Feature | Legacy artefacts | Modern implementation | Proving tests | Status |`. Parsers locate the table by that header; no other table in this file has it.
- One table row per line. A line break inside a cell is written `<br>`, never a raw newline. A `|` inside a cell is escaped as `\|`.
- The table has exactly 22 rows, with the IDs `F-001` to `F-022` in ascending order, each once. The ID cell holds only the ID.
- Legacy artefacts: legacy paths are written in backticks, repository-relative and starting with `Erewhon/`. JADE sources are cited `[Erewhon/<file>:<locator>]`, one file per bracket: `<file>` is the file's path below `Erewhon/`, and `<locator>` is one or more line spans separated by `, `, each `L<n>` or `L<n>-<m>` with 1 ≤ n ≤ m ≤ the file's line count.
- Modern implementation: a backticked token that starts with `src/`, `tests/`, `web/` or `docs/`, or is `ErewhonModern.sln`, is a path relative to `ErewhonModern/` of a file or a directory, or a glob pattern over such paths (`*` within one segment, `**` across segments). `<path>#<Member>` names a member declared in that file. Every other backticked token is a name that is not resolved: a route, an OpenAPI document, a CLI verb, a tool or a JADE construct. The cell is `None` only when the Status cell states the reason.
- Proving tests: backticked test tokens only, one token per test, in the syntax of `docs/migration/behaviour-catalogue.md`: an xUnit test as `Class.method`, or `Class.*` for every test of that class; a catalogue test always with its class (`BehaviourCatalogueTests.B07_ItemPriceZeroIsRejected`); a React or Playwright test as its file path (`web/src/shop/ShopPage.test.tsx`, `web/e2e/checkout.spec.ts`). A row with no test holds `—`.
- Status starts with one of `Implemented`, `Implemented (<qualifier>)`, `Replaced by React admin area`, `Replaced by React shop area`, `Replaced (<qualifier>)` and `Subsumed by PostgreSQL`. `Subsumed by PostgreSQL` is followed by `: ` and the facts that settle it. A qualifier that names a part not ported, and a Status whose row has `None` as its Modern implementation, cite the reason as a D-ID.
- Every `D-` ID in this file exists in the decision table of `docs/migration/decision-log.md`.
