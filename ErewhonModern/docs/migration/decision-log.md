# Decision log

This log is the single source of rationale for everything under `ErewhonModern/`: code comments state only what code does, and every other record (`docs/migration/behaviour-catalogue.md`, `docs/migration/feature-traceability.md`, `docs/migration/traceability-matrix.md`, `docs/migration/final-report.md`, `docs/operations.md`, `docs/rest-api.md`) cites the reasons recorded here by D-ID.

## Machine-read format

`TraceabilityCoverageTests` and `LegacyInventory` parse this file (D-48). The contract:

- The decisions are one table under `## Decisions` with the header `| ID | Decision | Alternatives | Reason | Risks |`. Parsers locate the table by that header.
- Each row is one line. A cell never holds a raw newline (`<br>` separates parts within a cell) and never holds a `|` except escaped as `\|`.
- IDs are zero-padded two-digit `D-01`, `D-02`, …, ascending and unique; the ID cell holds only the ID. D-01 to D-49 are the planned decisions; D-50 onward record decisions taken while the files were written.
- Cross-references inside cells use the IDs `B-xx`, `T-xx`, `C-xx`, `Q-xx`, `EE-xx` (`docs/migration/behaviour-catalogue.md`), `F-0xx` (`docs/migration/feature-traceability.md`) and `D-xx`. JADE sources are cited `[Erewhon/<file>:<locator>]`, one file per bracket: `<file>` is the file's path below `Erewhon/`, and `<locator>` is one or more line spans separated by `, `, each `L<n>` or `L<n>-<m>` with 1 ≤ n ≤ m ≤ the file's line count (for example `[Erewhon/ErehwhonExternalInterfacesSchema.scm:L1933]` and `[Erewhon/ErehwhonExternalInterfacesSchema.scm:L2368, L2468-2473]`). Paths are written in backticks: paths of target files are relative to `ErewhonModern/`, and paths of legacy files are repository-relative and start with `Erewhon/`.
- A new decision is appended as a new last row whose ID is the last ID plus one. IDs are never renumbered or reused. Every `D-` ID written anywhere under `ErewhonModern/` must exist in this table, so an ID is cited only once its row exists.
- The `## Request contradictions` table maps each contradiction to the decision that settles it.
